# OZ Price Analyzer 0.5.23

- Все положительные нераспределенные доходы Ozon включаются в налогооблагаемую базу.
- Нераспределенные расходы не уменьшают налоговую базу при объекте УСН «Доходы».
- Добавлен импорт актов Ozon PDF о премиях и компенсациях, которых нет в отчете по начислениям.
- PDF автоматически относится к отчету по начислениям за тот же календарный месяц.
- Дополнительный доход не включается в товарную выручку и товарную чистую прибыль, но увеличивает итог отчета после вычета налога.
- Налоговая база и налог с нераспределенных доходов отдельно показаны в приложении и экспортируемом XLSX.
- Старые отчеты получают новое правило автоматически по сохраненной «Разбивке»; для отсутствующего PDF-дохода требуется повторный импорт месяца вместе с актом.

# OZ Price Analyzer 0.5.17

- В «Обзоре» добавлены доли средней комиссии, полной логистики, баллов и чистой прибыли от выручки.
- Те же показатели добавлены в строки таблицы «Обзор» по каждому товару.
- В «Динамике» добавлены четыре процентных столбца и возможность строить по ним график.
- В экспортируемом XLSX новые показатели занимают свободные столбцы AH:AK и рассчитываются формулами по товарам и по итогу отчёта.
- Полная логистика включает прямую и обратную логистику.
- На вкладке «Обзор» добавлена кнопка «Настроить столбцы…».
- В отдельном окне настройки можно включать и выключать столбцы, а также менять их порядок.
- «Отмена» закрывает окно без изменений, «Сохранить» применяет и сохраняет настройку в базе приложения.
- Состав и порядок столбцов синхронизируются с отдельным окном таблицы «Обзор».

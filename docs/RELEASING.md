# Выпуск Windows-версии

## Что получает пользователь

Готовая поставка — переносимый ZIP `OZPriceAnalyzer-Windows-x64-v<версия>.zip`. После распаковки запускается `OZPriceAnalyzer.exe`; Python и Microsoft Excel пользователю не нужны. База, настройки, себестоимость, история и сохраненные исходные отчеты хранятся отдельно в `%LOCALAPPDATA%\OZPriceAnalyzer`, поэтому замена папки программы не удаляет рабочие данные.

## Единая версия

Версия задается в `ozon_app/__init__.py`. Из нее автоматически формируются:

- версия Python-пакета;
- заголовок и окно «О программе»;
- свойства Windows-файла `OZPriceAnalyzer.exe`;
- имя ZIP-архива.

## Автоматическая сборка

Workflow `.github/workflows/windows-build.yml` запускает тесты и собирает Windows x64 ZIP:

- при изменениях в `main` и рабочей ветке `agent/initial-python-app`;
- при создании тега `v*`;
- вручную через `Actions` → `Windows application` → `Run workflow`.

Готовый ZIP находится в артефакте `OZPriceAnalyzer-Windows-x64` соответствующего запуска GitHub Actions и хранится 30 дней.

## Локальная сборка

На Windows запустите `build_windows.bat`. Скрипт создаст виртуальное окружение, выполнит тесты, соберет приложение и положит ZIP в папку `artifacts`.

## Цифровая подпись

Без сертификата сборка остается работоспособной, но Windows может показать предупреждение о неизвестном издателе. Для подписи добавьте в GitHub Actions Secrets:

- `WINDOWS_CERTIFICATE_BASE64` — PFX-сертификат, закодированный Base64;
- `WINDOWS_CERTIFICATE_PASSWORD` — пароль PFX.

При наличии обоих секретов workflow подпишет `OZPriceAnalyzer.exe` алгоритмом SHA-256, добавит доверенную временную метку и проверит подпись до упаковки. Сам сертификат и пароль в репозиторий не попадают.

## Порядок выпуска

1. Изменить `__version__` и проверить пользовательские изменения.
2. Выполнить `python -m unittest discover -s tests -v`.
3. Объединить изменения в `main`.
4. Создать тег той же версии, например `v0.2.0`.
5. Дождаться успешного workflow и скачать Windows ZIP.
6. Проверить запуск на чистой Windows и свойства цифровой подписи.

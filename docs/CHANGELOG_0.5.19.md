# OZ Price Analyzer 0.5.19

- Windows-приложение теперь работает в режиме единственного экземпляра.
- Повторный запуск `OZPriceAnalyzer.exe` не создает второе окно и второй интерфейс.
- Если первое окно свернуто, оно восстанавливается и выводится на передний план.
- Защита срабатывает до открытия базы данных и построения интерфейса.
- Идентификатор экземпляра автоматически освобождается после штатного закрытия или аварийного завершения процесса.
- Windows smoke-test теперь отдельно проверяет повторный запуск и восстановление свернутого окна.
